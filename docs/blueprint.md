# **App Name**: Flick Flow

## Core Features:

- Play/Pause Control: Play and pause video content, including displaying an appropriate icon.
- Progress Bar: Scrub through the video using a user-friendly progress bar.
- Full-Screen Mode: Toggle full-screen mode for an immersive viewing experience.
- Volume Control: Adjust volume using an interactive volume slider.
- URL parameter parsing: Accept direct links to videos via URL parameters

## Style Guidelines:

- Background color: Dark gray (#121212) to provide a modern look.
- Primary color: Medium Gray (#4F4F4F) for interface elements.
- Accent color: Vibrant red (#FF4500) for highlights and controls to draw user attention.
- Body and headline font: 'Inter' (sans-serif) for a modern, neutral look that ensures readability.
- Use minimalist, vector-based icons for play, pause, full-screen, and volume controls.
- Responsive design to adapt to various screen sizes and devices.
